# Security policy

This extension shows what [cloudpin](https://github.com/paureis/cloudpin) reports and follows
[cloudpin's security policy](https://github.com/paureis/cloudpin/blob/main/SECURITY.md). Please report a security
problem in either one privately, through
[GitHub's private vulnerability reporting](https://github.com/paureis/cloudpin-vscode/security/advisories/new) on
this repository or [on cloudpin's](https://github.com/paureis/cloudpin/security/advisories/new), rather than in a
public issue. Examples for this extension: a file in a repository that the extension runs in place of the installed
cloudpin, or that cloudpin's launcher or the switch terminal picks up in place of the program it names (such as
`node`); anything it runs in Restricted Mode; a hover that renders a link, image or HTML from cloudpin's output, or
lets a command run; or the extension showing, logging or storing a token or credential value.
